# Gaurav Upadhyay — Portfolio

Personal portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this repository to GitHub
2. Import the project on [vercel.com](https://vercel.com/new)
3. Framework: **Vite** (auto-detected)
4. Build command: `npm run build`
5. Output directory: `dist`

No environment variables required.

## Tech Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3
- Lucide Icons
